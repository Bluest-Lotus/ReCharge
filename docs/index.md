# Project ReCharge

**Reclaim lithium. Reduce waste. Recharge the future.**

Project ReCharge is a student-led sustainability and engineering initiative exploring responsible recovery of lithium-ion cells from disposable vape devices, recycling pathways, and the Phoenix Pack powerbank prototype.

This site is a living project record. Prototype concepts and future goals are not certified products or established production capabilities.
